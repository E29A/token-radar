How the value is derived

Every implied value on this board is one formula over the snapshot’s own figures — no protocol is priced by name:

implied value = TVL × category multiple × momentum × seasoning, capped at 5 × TVL

  • Category multiple. For each category, the median market-cap / TVL of the snapshot’s own protocols whose token already trades — the launches that already happened, pricing the ones that have not. Each ratio is winsorised to [0.005, 10] (a token worth more than 10× its protocol’s TVL prices something else), shrunk toward the global median with weight 5 so a category with one shaky comparable cannot run away, and clamped to [0.05, 1.5]. A category with no traded comparable uses the global median.
  • Momentum. 1 + 0.75 × the 7-day TVL change, with the change clamped to ±40%: a strong week lifts the claim by at most 30%, a bad one cuts at most 30%. Unreported is neutral.
  • Seasoning. 1 + 0.07 for every year the protocol has been tracked with no token recorded, up to 6 years. A protocol that has run for years and still records no token has the users — and the launch — of a survivor. An unknown listing date is neutral, never a penalty.
  • The board’s screen. The ranked board applies the watchlist’s own product rule at every TVL, not only above the $50M floor: no token recorded, and not a bridge, staking or wrapped product of one that trades, not an exchange venue, not a later version of a family. Products and venues sit in “Set aside”, traded tokens in the reference set — neither is ranked as a launch.
